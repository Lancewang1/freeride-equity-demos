STEP 01

市场在问：估值低了，盈利预期是否也降够了？

海底捞的主品牌需求能否企稳，新业务增长能否转化为利润和现金，而不只是收入规模？

市场讨论的证据有两层：JPM 10 月 16 日投资者反馈把“盈利预期是否充分重置”列为消费板块的关键争论；GS 9 月报告具体讨论海底捞短期翻台改善、新品牌投入与折旧压力。我们将它们与公司财报结合，归纳出上述公司级核心问题。它是有出处的研究归纳，不是声称所有投资者意见一致。[R09][R04]

问题编号多头需要证明什么空头担心什么
C1 主品牌同店持续企稳，收入恢复能摊薄固定成本阶段性翻台改善不能抵消客单、门店调整和竞争
C2 新业务外卖、其他餐厅和加盟产生足够增量利润低毛利收入扩张，投入与折旧抵消规模效应
C3 定价市场已充分计入疲弱，盈利企稳即可支撑价值PE 看起来低，但分母中的盈利仍需下修

经营事实：2026H1；海底捞股价/共识快照：2026-10-08；市场讨论资料最晚至 10-16。本版不是截至 10-25 的全量信息更新。

STEP 02

核心逻辑：收入增长必须跨过利润与现金两道门槛

同店客流 × 客单 × 营业天数→主品牌收入＋新业务收入 × 各自利润率→集团利润→租赁/投资后的现金→可持续 EPS 与估值

主品牌仍是收入基础，弱同店会压制固定人工、租金和折旧的摊薄；新业务可以补收入，但外卖促销、供应链成本和开店投入决定留下多少利润。加盟商 GMV 不等于总部确认收入，总部加盟收入也不证明加盟商已经盈利。

因果环节要检验的假设模型处理
C1 同店 → 主品牌收入同店企稳是否扩展到整个主品牌同店作为需求证据；模型单独输入主品牌收入，不能把两者等同
C2 业务组合 → 利润低毛利业务扩张是否稀释集团利润率六项收入相加，再扣材料、人工、租赁、折旧和其他费用
C2 利润 → 现金利润增长是否转化为可支配现金另看 CFO 与扣除列示投资、租赁后的现金余额
C3 EPS → 股价需要盈利恢复，还是需要 PE 上升才能支撑现价先固定快照 PE 检验盈利，再单独计算所需估值倍数

单店与分业务成本未完整披露，因此采用集团经营桥。人工弹性、下半年季节性和新增业务净利率未被独立估计，不能把情景直接称为高置信盈利预测。

本次预期差判断：中性模型低于条件盈利参照约 9.3%；它暴露了“盈利恢复门槛仍然存在”的风险，尚不足以认定真实共识会下修。要让中性盈利支撑 HK$9.24，PE 需约 11.47 倍，而不是直接套用旧版演示的 16 倍。16 倍本身相对快照 10.4 倍要求约 54% 的重估。

压力 / 中性 / 改善情景具体假设

均为 H2 较 H1，并非同比，也未校准季节性。主品牌收入：−6% / +2% / +8%；外卖：−10% / +15% / +30%；其他餐厅：+5% / +15% / +30%；调味品：0 / +10% / +20%；加盟：+5% / +20% / +35%；其他收入不变。材料费率：+1 / 0 / −0.5 个百分点；其他费用率：+0.5 / 0 / −0.2 个百分点。人工一半随收入，固定部分涨薪 2% / 1% / 1%；其余固定项目沿用 H1。以上为分析者压力测试假设，不是管理层指引。此处三个情景都固定用 10.4 倍估值，不采用旧 JSON 中各异的演示 PE。

把预期门槛翻译回经营要求

在其他中性参数不变时，要达到上述盈利参照，H2 主品牌收入需较 H1 约 +11.7%；或材料费率在中性基础上下降约 2.38 个百分点。这是两种独立解法，不能同时相加，也不是已被股价唯一识别出的真实经营假设。

STEP 06

可跟踪结论：先验证利润恢复，再讨论估值修复

当前立场：经营中性偏弱；存在盈利门槛未被满足的风险，暂不把“便宜”当作已成立的投资结论。

历史判断置信度较高，H2 模型置信度有限，共识比较是有口径条件的判断。若同店企稳与利润率修复同时出现，才上调经营结论；若只有新业务收入高增而现金、利润继续承压，则维持或下调。
