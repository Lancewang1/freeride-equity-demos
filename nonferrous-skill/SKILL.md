# FREERIDE 有色股票研究

完整研究从商品开始，结束于可验证的股票判断。公司公告提供经营事实，卖方报告提供有出处的议题与预测；二者均不能替代宏观、商品价格、库存及行业供需证据。不要把公司盈利增长自动等同于股票正预期差。

## 执行路径
1. 确定资料截止日、证券及币种；识别矿山/冶炼/加工、产品、合并/权益敞口。每条资料分别记录观测期和公开日期，避免事后信息进入事前检验。
2. 先检查已有数据仓库，按 [数据与来源](references/depth-data.md)形成“已用/待核验/不用及原因”表。只补影响判断的缺口，优先官方免费来源和已授权接口。清洗结果不自动等于事实。
3. 先画同来源同频率的大宗走势及主要金属相对强弱，再按 [金属周期](references/commodity-cycle.md)研究相关金属。黄金走金融需求链，铜走矿端—精炼—库存—终端链；不要用一个“金属牛市”覆盖不同方向。
4. 根据带日期/页码的卖方议题、公司催化与新数据，提出 1–3 个可检验问题。用 [问题来源](references/question-sources.md)区分真实市场讨论、通用问题与分析者归纳；每个问题绑定数据、模型变量和证伪条件。
5. 按 [矿山到利润](references/mine-to-earnings.md)建历史量价成本桥与前瞻驱动模型；宏观/商品如何传导到实现售价必须可见。按 [项目与估值](references/projects-valuation.md)处理爬坡、权益、并购、现金流和价格隐含要求。其他金属及加工业务补读 [行业模块](references/modules.md)。
6. 用 [六步深度输出](references/depth-output.md)交付：市场问题 → 因果逻辑 → 实际数据 → 模型回答及逐项/整体方向 → 共识与 price-in → 可跟踪结论。commodity-first 是这六步的分析次序，不是另外堆一个宏观附录。

## 必须守住的口径
- 月均价不当日收盘；主力连续期货不当现货；实际利率用 bp；广义美元不叫 DXY。
- 产量≠销量，资源≠储量，名义产能≠可售产出；合并量与权益量不可混加，已权益计量不再乘权益比例。
- 仓单≠总库存；跨供应商重叠库存不能相加；矿产与精炼产量差额不等于供需缺口。
- 销售成本≠现金成本≠AISC；副产品收入单独核算时不可再次抵扣主产品成本。
- 分产品毛利≠集团税前利润≠归母；桥未闭合时列残差及可能组成，不能编造归因。
- 收购、少数股东、稀释股数、币种与估值日期会改变结论；未建模的重要变更不能悄悄设为经济影响零。
- 共识必须有日期、来源、年度和口径；单家预测不称一致预期，条件反解不称市场真实概率。

## 周期位置与判断台账（V4）
完整深研在商品驱动之后读取 [周期位置、资本响应与股票传导](references/cycle-position.md)：回答周期四问，给多维仪表盘，把行业开支连到项目供给，区分商品、盈利和股价时间线。对总量、结构和脉冲需求分别判断，不能以总量占比替代边际影响。
将结论按 [分歧裁判与判断台账](references/judgment-ledger.md)登记为可验证命题。动态更新时保留旧门槛、发布日期、结果与错误归因；不机械复制历史顶部阈值、轮动顺序或未校准概率。
