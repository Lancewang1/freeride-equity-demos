# 数据清单与语义核验

每条数据保留：series_id / source_url 或接口及参数（不含 token）/ observation_start,end / published_at / fetched_at / vintage / unit / currency / geography / frequency / product / consolidation_scope / definition / transform / raw_file_hash / source_page / confidence。
派生结果引用原始系列 ID、公式和版本；可追溯但不公开授权受限数据库全集。公开资料可引用必要事实，私有研报仅短事实与出处，API 整合文件及密钥不进入产物。

## 取数次序和用途
1. 本地已收集文件及清单：先查看原始字段与异常，不根据文件名推定语义。列出纳入模型、仅作旁证、被替换及未使用的组。
2. 商品长周期：World Bank 官方最新月价文件（验证最新观测月份，不因 HTTP 200 就认定最新）；日频使用 SGE/SHFE、已授权 Tushare；保留主力映射。
3. 宏观：FRED 实际/名义收益率、通胀预期、广义美元；中国 NBS/授权接口 PMI 和行业产销。字段名必须对照文档；未经核验不赋予经济含义。
4. 专有行业：WGC 供需/ETF，USGS 年度供给储量，ICSG 铜平衡，交易所库存/仓单/期限结构，海关贸易、协会及官方终端数据。最新失败记录状态、日期与替代范围，不制造替代值。
5. 公司公告：销量、实现价、成本、产量、权益、项目时间、资本开支、税/财务费用、少数股东、债务、现金；研报预测/共识加上出版日期、页码及其原始数据供应商。

## 易错点与验收
- warehouse 明细查重：日期×地区×仓库×产品×交割类别；先区分汇总行和明细，再区分境内/保税/国际铜。只聚合同一口径，找独立来源重叠期比对，差异未解时不能作为确定库存。
- 数值与单位核对：元/克×千克须乘 1000；千吨与吨不能直接相加；人民币与港元不直接比较；百分比字段可能缩放错误，从原价反算核验。
- SGE 基准上午/下午与收盘是不同时间/产品；缩写不擅自解释为夜盘。
- 原报告关键表视觉核对表头、列序、单位、页码及注释；累计数据相减的舍入差异保留记录。
- 数据修订：记录当前 vintage；未存历史 vintage 的 PMI/宏观不能用于严格事前回测。旧文件与官方值冲突时留审计记录，择可信新值，不静默覆盖全部历史。
- 截止日：财报发布日晚于股价日，则股价是公告前，不能声称反映新财报。季度需求不伪装为最新日频。

每份报告给覆盖矩阵：已收集跨度/条数→用于何问题→公式/图表→结论方向→尚缺变量。未使用的已下载数据允许留作储备，但不得把它算作独立验证。
