# 六步深度输出与验收

1. 市场关注点：最多三个核心问题，每个附原始讨论出处、日期、页码；研究者新增归纳明确标记。
2. 逻辑：大宗共振/分化→黄金及相关工业金属→公司的经济敞口→归母/现金→股票估值。展示因果链、必要假设和反例。
3. 数据：走势/利率/美元/供需/库存/曲线/终端/经营/预期各有数据用途；已下载但没用或被纠正也列原因。图表有单位、频率、观测截止和来源。
4. 模型裁决：每个证据标方向及力度，不机械投票；历史量价成本贡献与利润桥能加总；前瞻变量与商品判断有联系；至少一个反向/失败情景。明确“公司经营偏多”是否真的意味着“股票偏多”。
5. 共识/price-in：先验 vs 实际、自建 vs 共识、价格条件反解分开；指出旧共识/缺样本/币种/并表变化的影响；固定倍数盈利变化与重估分开。
6. 跟踪结论：指标、基点、频率、下次事件、升级/降级阈值、如何改变模型变量；阈值若为研究规则需明说。给需要补的最少关键数据，不以完整性不足回避已有证据的有限判断。

## 发布前验收
- 黄金与铜是否各自有价格走势、正反驱动、来源与结论？是否先从整体商品周期进入？
- 本地历史数据是否真正用于图表/判断/模型，而非只列下载清单？异常是否有处理记录？
- 关键表是否核对原页？时间、频率、单位、产销、权益、库存口径是否一致？
- 历史桥与前瞻零变化基线能否复算？反解阈值代回是否成立？网页和 Python 是否一致？
- 比较基期是否清楚？成本变化方向正确？负利润不展示正常 PE 估值？
- 最新重要并购/事故是否明确进入模型或以边界保留？未分配利润残差是否暴露？
- 页面无缺失图表/JS错误，窄屏可读，来源可追溯；没有 token、内部 API 文件、卖方报告全文或未授权数据库全集。
