# 六步研究叙事与验收

## 完整个股研究的主线
使用以下六步组织研究正文。财务表、情景和估值只是回答问题的工具，不能替代主线。每个核心问题用稳定编号贯穿六步；更新研究只需保留受到新信息影响的环节。

1. **市场主要关注点。** 以注明日期/机构/页码的研报、投资者反馈或公开问答证明市场正在讨论什么。区分行业通用问题、公司特定争议、分析者归纳；材料只支持板块关注点时，不声称已证明个股市场焦点。选影响盈利/估值的主问题，列多空双方需要成立的假设。
2. **核心问题的逻辑。** 写出经营变量→利润/现金→估值的因果链，说明每个传导机制、滞后与可推翻条件。不同业务模式和口径不能合并成一个模糊增长率。
3. **为回答问题收集的数据。** 每条证据对应问题编号、待检验假设、来源、报告期、披露时点、单位和范围；说明已收集、缺失、冲突及冲突处理。研报转引事实与公司公告矛盾时不能静默择优。
4. **数据和模型的裁决。** 对每条证据标记经营利好/利空/混合/不足，并解释传导与量级。整体结论按贡献大小、相互抵消、证据质量形成，不能数利好条数。展示至少一个关键经营驱动到盈利/现金的计算桥；模型必须明确回答主问题。历史归因与未来情景分别标记。
5. **共识、价格隐含要求和预期差。** 分开列市场共识、单家券商预测、管理层指引和自有模型。记录价格日、预测年度、币种、EPS调整定义、样本数及分布（没有则明确未知）。先对齐口径，再比较；价格/四舍五入PE反推EPS仅为近似值。价格、盈利与倍数不能唯一识别市场信念：提供假设下的盈利/经营门槛，不能写无依据的“已反映70%利好”。先固定同一倍数比较盈利影响，再单列重估贡献。跨时点FX/股数需披露敏感性，不能当同日精准估值。缺数据仍要尝试已有授权/公开来源，不能只用自选PE替代本环节。
6. **可跟踪结论。** 给当前经营立场、相对预期立场、置信度及受限结论。每项监测列基线、验证阈值及来源/模型依据、公告或数据节点、上调与下调条件。预计事件日已过时必须核查披露状态；未核查则写待核查，不能仍列作未来待发生。

## 经营方向与股价方向
“经营改善”不自动等于“股价利好”；只有对照当时可用、同口径预期，才能判断正/负惊喜。未来盈利情景低于共识不等于已经发生业绩miss。原始事实、卖方观点、假设、计算结果四类标记清楚。

## 模型与报告验收
- 从正文即可读出：核心问题是什么、为什么重要、每项数据在验证什么、整体支持哪方、价格要求什么、何时改变判断；不能仅把六个标题加在原财务堆砌上。
- 明确历史数据日、市场快照日、研报发布日和模型窗口。快照研究不能冒充全量最新更新；回顾旧价格时不得把后来披露的数据写成当时可知。
- 检查总分、税率、权益、股本、汇率、现金流与估值的口径；保留可重算输入和结果。新求解器以反代方式验证经营门槛，并测试方向、缺值、非正利润等重要边界。
- 公开展示使用文献引用和必要摘要；不把用户私有研报、模型原件、个人水印或API配置自动带入发布目录。

## 任务变体
财报更新：旧假设→实际→差异驱动→新预测→相对共识变化→逻辑增强/削弱。此前没有预测不能制造超预期。
同业比较：先确认商业模式、会计口径、租赁、权益和周期位置，再比较经营、现金与估值。
事件分析：事实、影响变量、幅度/滞后、情景概率与原判断变化分开。
